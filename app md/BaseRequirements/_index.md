# Base requirements — ticket index

- `01-view-the-base-requirements-checklist/` — Load and render the version's checklist grid (sections, headings, requirement text, desired-answer type, per-line trade count), with empty/loading/locked/viewer states.
- `02-insert-new-requirement-or-heading-rows/` — Add one, many (1–50), or one heading row to the checklist from the toolbar or right-click menu, propagating each new line onto every active trade.
- `03-edit-a-requirement-line-inline/` — Inline-edit a line's section, text, or desired-answer type, or toggle a row between heading and normal via the right-click menu, pushing the change to every trade's synced copy.
- `04-reorder-requirement-rows/` — Move a row up or down one position via the right-click menu, re-sorting it and every trade's synced copy without renumbering the rest of the list.
- `05-delete-a-requirement-row/` — Permanently delete a requirement/heading row from the checklist and every trade's copy via the right-click menu.
- `06-apply-a-checklist-template/` — Bulk-apply a reusable company checklist template's lines onto the current version's checklist, skipping duplicate text and backfilling any trade missing a line.
