# Bid board — ticket index

- `01-browse-search-filter-bid-board/` — Browse the trade-by-bid grid with search, quick filter pills, budget/unresolved/buyout toggles, and the budget-source selector.
- `02-pick-or-clear-a-bid/` — Click a posted bid tile to carry (or clear) it as the trade's picked value, with instant client recalculation and server confirmation.
- `03-trade-manual-adjustments/` — Set a trade's plug amount, adjustment to the picked bid, client note, and team note via the adjust modal.
- `04-bid-details-drawer/` — Open a bid's detail drawer to edit its base amount/status/name, create an online bid invite link, pick/clear it, or remove it.
- `05-add-a-bidder-to-a-trade/` — Add a new bidder/lane to a trade, matched against (or newly added to) the trade partner directory.
- `06-add-a-trade/` — Add a new trade by CSI code, optionally seeded from a scope kit, with standard scope lines and a default zone split.
- `07-edit-trade-details-and-delete-trade/` — Rename a trade, change its CSI code or bid-due date, or soft-delete it from the version.
- `08-zone-split-a-trade/` — Manually split a trade's value across the version's zones, or view the read-only split derived from Scope match zone amounts.
- `09-copy-trade-budgets-from-another-version/` — Copy every trade's budget value from a sibling version of the same project, matched by CSI code.
- `10-import-trades-and-bidders-from-excel/` — Upload the Gridline Excel template's Trades/Bidders sheets, review a dry-run check, and commit to bulk-add/update trades and bidders.
- `11-add-an-indirect-cost-item/` — Add a custom indirect cost line that appears in the roll-up section here and on the Price roll-up page.
- `12-export-bid-board/` — Export the current bid board as an Excel workbook or a PDF of bid quotes.
